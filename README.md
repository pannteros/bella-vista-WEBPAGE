# Bella Vista Pizzeria 🍕

> A responsive one-page restaurant website built with HTML, CSS, Bootstrap 5 and JavaScript.


## Περιγραφή | Description

**GR:** Ένα responsive one-page website για την πιτσαρία "Bella Vista" στην Αθήνα. Περιλαμβάνει πλοήγηση με smooth scroll, menu προϊόντων, ιστορία του εστιατορίου και φόρμα επικοινωνίας.

**EN:** A responsive one-page website for "Bella Vista" pizzeria in Athens. Features smooth scroll navigation, product menu, restaurant story and contact form.

## Εκκίνηση | Getting Started

**1. Clone το repository**
```bash
git clone https://github.com/pannteros/bella-vista.git
cd bella-vista
```

**2. Άνοιξε στο VS Code**
```bash
code .
```

**3. Τρέξε με Live Server**
- Εγκατέστησε το **Live Server** extension στο VS Code
- Δεξί κλικ στο `index.html` → **Open with Live Server**
- Ανοίγει αυτόματα στο: `http://127.0.0.1:5500`

> Δεν χρειάζεται καμία εγκατάσταση — το Bootstrap φορτώνεται από CDN.
